Issue #3402: the session-start fleet digest printed "endpoint: alive" for tmux
windows that did not exist.

Root cause, reproduced live against a real tmux 3.2a server: tmux answers a
display-message for an ABSENT target from the client's active window instead of
failing, so the endpoint probe read some other pane entirely.

  $ tmux display-message -p -t 'fm:fm-ghost-crew' '#{pane_id} (window=#{window_name})'
  %2 (window=fm-done-crew)  ; exit=0

  $ tmux list-windows -t fm -F '#{window_name}'   # fm-ghost-crew is NOT there
  fm-live-crew
  fm-dead-crew
  fm-done-crew
